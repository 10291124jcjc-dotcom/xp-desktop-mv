# <歌名> · XP 桌面版：制作文档（模板）

> 和源视频（改名为 `source.mp4`）放进同一个文件夹，在该文件夹打开 Claude Code，对它说：
> **"读 BRIEF.md，按步骤做，每到一个检查点停下来给我看。"**
> 完整填好的例子见 `examples/apt/BRIEF.md`。

## 0. 一句话目标
把一段 <时长> 秒的 MV 剪辑，重做成一段"<配色> Windows XP 桌面录屏"：MV 里的人被抠出来，在桌面、窗口、任务栏上唱歌跳舞；所有界面元素都用代码画出来，每一次点击、弹窗、切换都卡在节拍上。不生成任何新素材，所有人物画面都来自源视频。

## 0.5 核心创意：梗比画面重要
**主梗：<歌名> = <科技圈里的同名 / 谐音东西>**（APT. = Linux 的 `apt`；其他歌可以找命令、软件名、报错、硬件、AI 公司名……）

一条故事线：这个系统被 <主梗> 一步步"占领"。

梗库（起点，让 Claude 扩充到 20 条以上）：
- 双击 <歌名>.mp3 → 报错 …
- 终端按拍逐字敲出 …
- 托盘气泡 "发现新硬件：…"
- 连环报错 "… 已在运行""… 没有响应""是否结束 …？" [结束] [继续蹦迪]
- 任务管理器里全是 <主梗>.exe
- 结尾：关机画面 → 最后半秒闪一行小字

梗的规则：
1. 一眼就懂；每次出现的文字不超过 12 个汉字或 24 个英文字符
2. 先列 ≥20 条，标"秒懂 / 要想一下 / 看不懂"，只用秒懂的
3. 梗卡在强拍上
4. 不写歌词，梗只放在界面文案里

**→ 检查点 0：扩充后的梗库 + 分镜调整建议**

## 1. 输入与输出
- 输入：`source.mp4`（分辨率 / 帧率 / 时长）
- 输出：`out/<名>_v1.mp4`（1920×1080，30fps，H.264 CRF 16，原声，时长与源视频一致）；`out/contact_sheet.jpg`

## 2. 工作规则
1. 所有文件写在项目文件夹内（包括记忆、缓存、配置）
2. 按阶段做，每个检查点停下来
3. 不下载素材，只装 Python 包和抠像模型
4. 不用真实的 Windows logo、旗标、系统音效；系统名 / 公司名用戏仿
5. 歌词不自己写进画面，用原片自带的歌词画面
6. 每一帧都是时间 t 的纯函数

## 3. 源视频镜头表
| 源时间 | 内容 | 处理方式（不抠放进窗口 / 抠人 / 抠头像 / 全屏转场） |
|---|---|---|

## 4. 视觉风格
- 配色：标题栏渐变 `#… → #…`，窗口底色 `#…`，"开始"按钮 …
- 壁纸：<配色> 版 Bliss（代码画，不用真实照片）
- 字体：Tahoma / Verdana / Arial；中文用系统黑体

## 5. 参考分镜（时间 | 画面 | 梗）
分 5–6 章，每章一个文件 `shots/ch01.json …`。

## 6. 检查点
- **检查点 0**：梗库 + 分镜建议
- **检查点 1**：BPM、节拍图、每秒一帧拼图
- **检查点 2**：每个抠像片段 3 帧，分别放在棋盘格和深色底上
- **检查点 3**：5 张静帧（开机、桌面、媒体播放器、错误对话框、关机）
- **检查点 4**：480p 草稿 + `review_log.md` 里每章的最终分数（美术总监审核：平均 ≥ 8 且单项 ≥ 6，最多 3 轮）
- **检查点 5**：成片 + 拼图

## 7. 音效（可选）
主音轨不动；界面音效用代码合成，比原声低约 12dB；先做无音效版。
