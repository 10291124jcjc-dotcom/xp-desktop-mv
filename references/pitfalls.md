# 踩过的坑（第一次制作 APT. → Pinkdows XP）

## 环境
- **往项目外写文件会卡住整条流程。** 用 `env.ps1` 把 pip 缓存、TEMP、numba / matplotlib 缓存、`U2NET_HOME`（rembg 模型）、`PLAYWRIGHT_BROWSERS_PATH` 全部指到项目里；Python 包装进项目的 `.venv`。
- **Node 不一定有。** 用 Python 版 Playwright + `channel="msedge"`，直接调用本机 Edge，不下载浏览器。
- **中文路径：** OpenCV 的 `imread/imwrite` 打不开，改用 `np.fromfile` + `cv2.imdecode`，以及 `cv2.imencode().tofile()`。`subprocess` 读 ffmpeg 输出要加 `encoding="utf-8", errors="replace"`，否则会遇到 GBK 解码错误。
- **PowerShell 5.1 的 `Get-Content/Set-Content` 默认 ANSI，** 用它们改 UTF-8 源码会把中文和 `±`、`–` 改成乱码。改文件用编辑工具或 Python。
- **长补丁不要直接写进 bash 命令**（`python - <<'EOF'`），会被引号截断。先把补丁写成文件再运行。

## 分析
- **librosa 的 beat tracker 会漂**（147.8 vs 实际 148.96 BPM，±50ms）。要按底鼓起音拟合网格，并在开头、中间、结尾三段放大验证。
- **判断小节第一拍：** 最重的底鼓（开场第一下、停顿后重新进来那一下）通常是第 1 拍；再看底鼓 / 军鼓的分布。
- **黑边是深灰（RGB 约 19）不是纯黑；** 手写歌词会压到黑边上。cropdetect 要 `limit≈44`、`reset=1`，再对逐帧结果取中位数。
- **容器帧率可能虚标**（标 59.94，实际 30fps）。用 `nb_frames / duration` 核对。
- **用 ffmpeg 的 `fps=1` 滤镜抽"每秒一帧"会有半秒取整误差。** 拼图要按精确时间（`-ss` 放在 `-i` 后面）逐帧抽。
- **原片开头可能有几帧闪过别的画面**（APT. 的 0–0.17 秒），这不是 bug。

## 抠像
- **BiRefNet 明显好于 isnet / u2net_human_seg**（黑皮衣、腿、两个人）。没有 GPU 时 12 秒一帧，有 GPU（pip 装 `onnxruntime-gpu[cuda,cudnn]`，再调用 `preload_dlls()`）约 1.5 秒一帧。
- **原始 alpha 只跑一次存下来，** 清理参数随便调。
- **片段最后一帧可能已经是下一个镜头**（头像片段的第 360 帧已经是嘴唇）。用画面的颜色突变核对出入点。
- **保留区域别用直线硬切，** 会在头发上切出直角缺口。要挖掉的东西（镲片）用倾斜椭圆单独挖。
- **细支架粘在人身上时，** 先开运算断开再选连通块，最后把真实边缘补回来。
- **运动模糊会带出一层淡粉色的雾：** 用 alpha 重映射（`lo`）去掉；整个人被粉光染色（金发）时，做全身去粉（`global_spill`）。
- **头像缩小后，烘焙在素材里的 6px 白描边会变成 1px。** 改由引擎在渲染时画固定屏幕宽度的描边。
- **甩头、动态模糊造成的"没有脸"是素材本身。** 可以跳过这几帧（`skip`），或用界面元素挡住，并如实告诉导演。

## 引擎和分镜
- **屏保和视频窗口会在最后几帧露出原片的下一个镜头。** 用 `srcKeys` 把当前镜头拉伸 / 定格到时段结束。
- **XP 没有半透明：** 窗口打开用不透明的 4 帧缩放，关闭硬切。
- **点击前一定要让鼠标停在按钮上**（生成器的 `click()` 自动插停住关键帧），按下状态显示 2–3 帧。
- **鼠标停着时别压在梗文字、人脸、气泡上。**
- **任务栏按钮按打开顺序固定，** 不要跟着焦点换位置；同一时间只有一个窗口是激活色，非激活要明显更灰。
- **"开始菜单""Ubuntu"这类结尾梗至少要停 10 帧以上，** 字号要和主文案接近，否则手机上读不到。
- **人物坐 / 站在任务栏上：** 每帧把 alpha 最低点对齐到任务栏上沿，再加接触阴影；不要靠手算 y。
- **人物会挡住左侧桌面图标，** 图标放右侧一列更省事。
- **文字放进窗口时，** 中文用中文字体排在前面（全角标点才对）；等宽字体的回退字体也要设成中文字体。
- **预览（960×540）用来审节奏和构图。** 1px 级的细节要在 1080p 原尺寸下复核，美术总监在预览里看到的"灰字""半角"多半是缩小造成的。

## 交付
- **成片 1080p 有二十多 MB，** 用户在手机上可能看不了，另压一个 720p（CRF 24，约 5MB）。
- **对比视频：** 左原片右成片 `hstack`，用 drawtext 标注。**原 MV 有版权，** 放进公开仓库前要提醒用户。
